# WET Salamander Assets

## Token Logo
- **File:** `wet-salamander-logo.png`
- **Format:** PNG (transparent background recommended)
- **Size:** 256x256px or larger
- **Description:** WET Salamander token logo with gold and blue design

## How to Use

### 1. Upload to IPFS (Pinata)
1. Go to: https://pinata.cloud
2. Sign up (free)
3. Upload `wet-salamander-logo.png`
4. Copy your IPFS hash (e.g., `QmXXX...`)
5. Access via: `https://gateway.pinata.cloud/ipfs/QmXXX`

### 2. Submit to Etherscan
1. Go to: https://sepolia.etherscan.io/
2. Find your WET token contract
3. Click "Verify & Publish"
4. Under "Token Logo", paste your IPFS URL or direct image URL
5. Submit for approval

### 3. Add to MetaMask
1. Open MetaMask
2. Go to "Add Token" → "Custom Token"
3. Paste your contract address
4. Symbol: WET
5. Token image URL: Your IPFS or direct URL

### 4. Add to Uniswap/DEX
1. Submit logo via their token registry
2. Requires verification
